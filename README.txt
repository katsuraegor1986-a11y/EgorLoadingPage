Заставка Егора Кацуры для тестирования в Render Static Site.

Файлы: index.html, style.css, script.js, loading-screen.jpg.

Заставка тестирует запуск текущего сайта https://egorkatsura.onrender.com/ и после ответа перенаправляет на него.
Важно: пока не подключайте к этому Static Site основной домен егоркацура.рф. После перенаправления адресная строка перейдёт на onrender.com. Перед использованием на основном домене нужно отдельно продумать схему домена, чтобы не ухудшить SEO.
